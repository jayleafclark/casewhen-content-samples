Microsoft Power BI Preise: Die echte Zahl

Quick answer. Microsoft Power BI Preise beginnen bei rund 14 Euro pro Nutzer und Monat für Power BI Pro. Ein Team von zehn Personen zahlt damit etwa 140 Euro im Monat. Premium per User liegt bei rund 24 Euro, eine Kapazität startet bei etwa 5.000 Euro. Für die meisten Häuser reicht Pro. ---

Microsoft Power BI Preise beginnen bei rund 14 Euro pro Nutzer und Monat. Das ist die echte Zahl, die Sie für eine erste Entscheidung brauchen. Ein Team von zehn Personen liegt damit bei etwa 140 Euro im Monat, und für die meisten mittelständischen Häuser ist damit die Frage schon beantwortet. Teuer wird Power BI fast nie an dieser Zahl.

Dieser Beitrag zeigt Ihnen die drei Preisstufen im Klartext, die eine Schwelle, an der die Rechnung plötzlich springt, und die Stelle, an der die eigentlichen Kosten entstehen. Das reicht, um die Lizenzfrage auf Ihrer nächsten Vorstandssitzung in zwei Sätzen zu beantworten statt in einer halben Stunde Diskussion.

Microsoft Power BI Preise: wie lautet die echte Zahl?

Es gibt genau drei Wege, für Power BI zu zahlen, und sie funktionieren grundlegend anders. Die ersten beiden rechnen pro Kopf: Power BI Pro und Premium per User. Der dritte ist eine Kapazität, eine feste Monatspauschale für Rechenleistung, unabhängig davon, wie viele Menschen zusehen. Fast jede überraschende Rechnung entsteht am Übergang von der Abrechnung pro Kopf auf die Pauschale.

Die folgende Übersicht zeigt, was jede Stufe kostet und für wen sie gedacht ist. Die Werte sind grobe Euro-Richtwerte für die Planung, denn Microsoft nennt Listenpreise oft in Dollar.

Die Faustregel darunter ist kurz: Pro pro Kopf, eine Kapazität erst dann, wenn die Zahlen dafür sprechen. Alles andere ist teure Vorsicht.

Was kostet Power BI pro Nutzer wirklich?

Mit hoher Wahrscheinlichkeit zahlen Sie heute pro Kopf. Power BI Pro liegt nach Microsofts Liste bei rund 14 Euro pro Person und Monat, und damit darf diese Person Berichte bauen und ansehen. Die Rechnung bleibt linear: jeder zusätzliche Nutzer ist genau eine Lizenz mehr, also rund 14 Euro obendrauf. Power BI Desktop zum Bauen der Berichte kostet nichts, erst das Teilen im Team braucht eine Lizenz.

So sieht ein normaler Start aus. Drei, vier Analysten, dazu eine Handvoll Führungskräfte, die nur lesen wollen. Sagen wir zehn Lizenzen, das sind rund 140 Euro im Monat. Auf der Rechnung passiert nichts Überraschendes, solange jede Person, die einen Bericht öffnet, ihre eigene Lizenz hat. Die MS Power BI Kosten sind an dieser Stelle veröffentlicht und planbar, und genau deshalb ist die Lizenz selten das Problem.

Was kosten Power BI Premium und eine Kapazität?

Hier verrechnen sich Häuser am häufigsten. Premium per User schaltet größere Datenmodelle und häufigere Aktualisierung frei. Der Reflex ist, das ganze Team von Pro auf Premium zu heben. Rechnen wir das durch. Zehn Personen auf Pro sind rund 140 Euro im Monat, zehn Personen auf Premium per User rund 240 Euro. Sie zahlen 100 Euro mehr, obwohl in den meisten Teams nur zwei oder drei Menschen wirklich große Modelle bauen. Der saubere Weg ist, genau diese zwei, drei Köpfe auf Premium zu heben und den Rest auf Pro zu lassen.

Der große Sprung kommt an dem Tag, an dem Sie Zuschauer wollen, die nicht jeder eine eigene Lizenz haben. Im Pro-Modell braucht jede Person, die einen Bericht öffnet, ihre eigene Lizenz. Sobald hundert Leute oder das ganze Haus ein Dashboard lesen sollen, führt der Weg über eine Kapazität. Freies Zuschauen für Menschen ohne eigene Lizenz gibt es erst ab der Stufe F64, die monatlich bei rund 5.000 Euro auf Jahresreservierung startet.

Damit schreibt sich die Break-even-Rechnung von selbst. 5.000 Euro geteilt durch 14 Euro sind rund 360. Die Kosten Power BI Premium lohnen sich also erst zwischen etwa 350 und 500 reinen Zuschauern, sobald Sie die Autoren mitrechnen, die weiter ihre eigene Lizenz brauchen. Die teure Falle ist die Mitte: Häuser springen bei 80 Zuschauern auf eine 5.000-Euro-Kapazität, obwohl 80 Pro-Lizenzen sie rund 1.100 Euro gekostet hätten.

Was kostet der Power BI Report Server?

Ein kurzer Blick auf einen Sonderfall, den viele im Mittelstand übersehen. Wer Berichte aus Datenschutzgründen im eigenen Haus statt in der Cloud betreiben muss, fragt nach dem Power BI Report Server, der Berichte auf einem eigenen Server bereitstellt.

Der Report Server hat keinen eigenen Preis pro Nutzer. Sie bekommen ihn auf zwei Wegen. Entweder über eine Power BI Premium Kapazität, dann ist er in deren Monatspreis enthalten. Oder über eine SQL Server Enterprise Lizenz mit Software Assurance, die Sie ohnehin für Ihre Datenbank halten. Die Power BI Report Server Kosten stecken also in einer dieser beiden Lizenzen und tauchen selten als eigene Position auf. Für die meisten Häuser ist das kein Thema. Es wird eines, wenn Compliance oder eine Behörde die Cloud ausschließt, und dann gehört diese Rechnung früh in die Planung.

Wo entstehen die eigentlichen Kosten wirklich?

An der Lizenz sparen Sie ein paar Hundert Euro im Monat. An einem Datenmodell, dem niemand traut, verlieren Sie ein Vielfaches davon, und zwar unsichtbar.

Im Alltag sieht das so aus. Der Umsatz auf Folie drei im Vorstandspaket weicht von der Zahl im Vertriebsbericht ab. Die erste Viertelstunde der Sitzung geht dafür drauf, zu klären, welche Zahl stimmt. Am Ende fällt die Entscheidung über Budget oder Personal auf Basis der Zahl, die am lautesten verteidigt wurde. Das kostet kein Lizenzgeld, aber es kostet gute Entscheidungen. Nur 40 Prozent der Führungskräfte vertrauen den Daten, mit denen sie arbeiten, immer (Talend). Auch der Monatsabschluss hängt daran: acht Tage gelten als vertretbar, die schnellsten Häuser liegen unter drei Tagen (SolveXia), und die Differenz steckt fast immer in manueller Nacharbeit, nicht in der Lizenzstufe.

Wie groß dieser Posten wird, lässt sich beziffern. Gartner schätzt die durchschnittlichen Kosten schlechter Datenqualität auf 12,9 Millionen Dollar pro Jahr und Organisation (Gartner). Neben dieser Zahl ist die Frage nach 14 oder 24 Euro pro Nutzer eine Nebensache. Deshalb prüfen wir bei einer Kostenfrage immer zuerst, ob jede wichtige Kennzahl genau eine verbindliche Definition hat, und erst danach die Lizenzstufe.

Ein guter Endzustand ist einfach zu beschreiben. Sie kennen Ihre Nutzerzahl, Sie wissen, welche Stufe für diese Zahl günstiger ist, und die Zahlen im Bericht stimmen über alle Abteilungen überein. Dann ist der Sprung auf eine Kapazität keine Überraschung mehr, sondern eine Entscheidung, die Sie kommen sehen.

Häufige Fragen

Was kostet Microsoft Power BI pro Nutzer und Monat? Power BI Pro liegt bei rund 14 Euro pro Person und Monat, Premium per User bei rund 24 Euro. Beide rechnen pro Kopf, jeder zusätzliche Nutzer ist genau eine weitere Lizenz. Power BI Desktop zum Bauen der Berichte ist kostenlos, das Teilen im Team braucht aber eine Lizenz.

Ist Power BI Pro oder Premium per User günstiger? Für die meisten Nutzer ist Pro günstiger. Premium per User lohnt sich nur für die einzelnen Personen, die große Modelle bauen oder häufiger aktualisieren müssen. Heben Sie nur diese zwei, drei Köpfe auf Premium, nicht das ganze Team.

Ab wann lohnt sich eine Kapazität statt Einzellizenzen? Grob ab 350 bis 500 echten Zuschauern. Eine F64-Kapazität startet bei rund 5.000 Euro monatlich, eine Pro-Lizenz bei rund 14 Euro. Unter dieser Schwelle ist die Abrechnung pro Kopf fast immer billiger.

Was kostet der Power BI Report Server? Er hat keinen eigenen Preis pro Nutzer. Sie erhalten ihn über eine Power BI Premium Kapazität oder über eine SQL Server Enterprise Lizenz mit Software Assurance. Die Power BI Report Server Kosten stecken also in einer dieser beiden Lizenzen.

Warum ist meine Rechnung höher als der Listenpreis? Meist läuft die Kapazität auf stundenweiser Abrechnung statt auf Jahresreservierung, was fast das Doppelte kosten kann. Dazu zahlen alle Autoren weiter ihre eigene Lizenz, auch wenn eine Kapazität aktiv ist.

Sind die Microsoft Power BI Preise in Euro oder Dollar angegeben? Microsoft nennt Listenpreise oft in Dollar. Auf Ihrer Rechnung erscheinen sie in Euro, umgerechnet zum jeweiligen Tarif. Die Richtwerte hier sind grobe Euro-Werte für die Planung.
