Warum Ihr KPI Dashboard falsche Zahlen zeigt und wie Sie es reparieren

Quick answer. Ein KPI Dashboard ist eine Übersicht in Power BI, die Ihre zentralen Kennzahlen aus einem sauberen Datenmodell zusammenführt und automatisch aktualisiert. Ein gutes Dashboard zeigt fünf bis neun Zahlen, jede mit einer klaren Definition als DAX-Measure, damit jede Zahl im Vorstand nachvollziehbar und geprüft ist. --- Die meisten Teams bauen ihr KPI Dashboard falsch, und das zeigt sich in der ersten Vorstandssitzung. Zwei Manager öffnen dieselbe Kachel, sehen zwei verschiedene Umsatzzahlen, und ab diesem Moment redet niemand mehr über die Zahl, sondern nur noch darüber, welche Zahl stimmt. Genau hier entscheidet sich, ob ein KPI Dashboard ein Werkzeug ist oder ein weiterer Streitpunkt.

Das Problem liegt fast nie an der Optik. Es liegt darunter, im Datenmodell. Dieser Text zeigt Ihnen, warum die Zahlen auseinanderlaufen und welche konkreten Schritte in Power BI das beheben.

Warum zeigt Ihr KPI Dashboard falsche Zahlen?

Der häufigste Grund ist eine flache Tabelle. Viele KPI Dashboards entstehen aus einem einzigen Excel-Export, in dem Umsatz, Region, Produkt und Datum alle in derselben breiten Tabelle stehen. Sobald Sie darauf filtern, zählt Power BI Zeilen doppelt, weil dieselbe Bestellung in mehreren Zeilen auftaucht. Das Ergebnis sind Summen, die je nach Filter springen.

Der zweite Grund ist eine fehlende Definition. Wenn "Umsatz" an einer Stelle den Bruttowert und an anderer Stelle den Wert nach Rabatt meint, dann rechnet jede Kachel etwas anderes aus. Das ist keine Kleinigkeit: 94 Prozent der Geschäfts-Tabellen, mit denen Entscheidungen getroffen werden, enthalten Fehler (Poon et al., 2024). Ein Dashboard, das direkt auf solchen Tabellen aufsetzt, erbt jeden dieser Fehler.

Der dritte Grund ist Vertrauen. 67 Prozent der Organisationen vertrauen den Daten, mit denen sie entscheiden, nicht vollständig (Precisely und Drexel LeBow, 2025). Wenn Ihr Vorstand die Zahl auf der ersten Kachel schon einmal korrigieren musste, glaubt er auch der zweiten Kachel nicht mehr.

Wie bauen Sie das Datenmodell hinter einem KPI Dashboard?

Ein belastbares KPI Dashboard steht auf einem Sternschema. Das bedeutet: Sie teilen Ihre eine breite Tabelle in eine Faktentabelle und mehrere Dimensionstabellen auf. Die Faktentabelle enthält die Ereignisse mit Zahlen, also zum Beispiel jede Rechnungszeile mit Menge und Betrag. Die Dimensionstabellen enthalten die beschreibenden Angaben, also Kunde, Produkt, Region und ein eigenes Datum.

Diese Datenmodellierung verbinden Sie über 1:n-Beziehungen. Eine Kalender-Dimension zeigt auf viele Rechnungszeilen, ein Produkt zeigt auf viele Rechnungszeilen. Power BI filtert dann sauber von der Dimension in die Fakten, und die Doppelzählung verschwindet.

Wenn Sie mit mehreren Quellen arbeiten, lohnt sich der Blick auf saubere Datenmodelle statt auf einen einzigen Riesenexport. Eine gemeinsame Kalendertabelle, die alle Fakten teilen, ist der wichtigste Baustein. Ohne sie funktionieren Vergleiche wie "gleicher Monat im Vorjahr" nicht zuverlässig. In Power Query bereinigen Sie die Rohdaten, in der Modellansicht ziehen Sie die Beziehungen, und erst danach beginnt die eigentliche Arbeit an den Kennzahlen.

Welche Kennzahlen gehören auf ein KPI Dashboard?

Weniger, als Sie denken. Ein Vorstand liest fünf bis neun Kennzahlen pro Ansicht, danach sinkt die Aufmerksamkeit. Wählen Sie die Werte, die eine Entscheidung auslösen, und lassen Sie den Rest auf einer Detailseite.

Jede Kennzahl definieren Sie als Measure in DAX, nicht als Spalte. Ein Measure rechnet im Moment der Anzeige und passt sich jedem Filter an. Umsatz schreiben Sie zum Beispiel als `Umsatz = SUM(Fakten[Betrag])`, und die Marge als eigenes Measure, das auf Umsatz und Kosten aufbaut. So gibt es genau eine Definition pro Zahl, und diese eine Definition steht im Modell.

Der Vorteil dieser Datenmodellierung: Wenn jemand fragt, wie eine Kennzahl gerechnet ist, öffnen Sie das Measure und zeigen die Formel. Die Zahl ist prüfbar. Genau das schließt die Vertrauenslücke, die eine flache Tabelle offen lässt. Poor Data Quality kostet Organisationen im Schnitt 12,9 Millionen US-Dollar pro Jahr (Gartner), und ein Großteil davon entsteht durch Zahlen, die niemand mehr nachvollziehen kann.

Wie halten Sie ein KPI Dashboard aktuell und vertrauenswürdig?

Ein Dashboard, das gestern stimmte, ist heute wertlos, wenn niemand es aktualisiert. In Power BI planen Sie die Aktualisierung: mit einer Pro-Lizenz bis zu achtmal am Tag, mit Kapazität deutlich häufiger.

Bei großen Faktentabellen nutzen Sie die inkrementelle Aktualisierung. Dabei laden Sie über die Parameter RangeStart und RangeEnd nur die neuen Zeilen nach, statt jedes Mal die ganze Historie zu ziehen. Das verkürzt die Aktualisierung von Stunden auf Minuten.

Damit nicht jeder alles sieht, richten Sie Sicherheit auf Zeilenebene ein, die sogenannte Row-Level Security. Eine Regionalleiterin sieht dann nur ihre Region. Bevor Sie das Dashboard freigeben, prüfen Sie das mit der Funktion "Als Rolle anzeigen", damit keine Zahl an die falsche Person geht.

Und Sie trennen die Umgebungen. Mit Bereitstellungspipelines schieben Sie Änderungen von Entwicklung über Test nach Produktion, ohne die Live-Version zu berühren. So testen Sie eine neue Kennzahl, bevor der Vorstand sie sieht.

Wie bauen Sie Ihr erstes belastbares KPI Dashboard? Schritt für Schritt

Diese sechs Schritte können Sie heute umsetzen:

  1. Trennen Sie Ihre breite Tabelle in eine Faktentabelle und Dimensionstabellen für Kunde, Produkt, Region und Datum.
  2. Erstellen Sie eine eigene Kalendertabelle und verbinden Sie sie über 1:n-Beziehungen mit den Fakten.
  3. Legen Sie in Power Query die Bereinigungsschritte an, damit sich die Rohdaten bei jeder Aktualisierung selbst korrigieren.
  4. Schreiben Sie jede Kennzahl als DAX-Measure mit einer einzigen, dokumentierten Definition.
  5. Wählen Sie höchstens neun Werte für die Hauptansicht und schalten Sie inkrementelle Aktualisierung sowie Row-Level Security ein.
  6. Prüfen Sie mit "Als Rolle anzeigen" und geben Sie erst danach über eine Bereitstellungspipeline frei.

Häufige Fragen

Was ist ein KPI Dashboard genau? Ein KPI Dashboard ist eine Ansicht, die Ihre wichtigsten Kennzahlen aus einem geprüften Datenmodell bündelt und automatisch aktualisiert. Jede Zahl hat eine feste Definition, damit alle im Raum über dieselbe Kennzahl sprechen.

Brauche ich ein Sternschema oder reicht eine Tabelle? Für zwei, drei Zahlen reicht eine Tabelle. Sobald Sie nach Region, Produkt und Zeit filtern, brauchen Sie ein Sternschema, sonst zählt Power BI Zeilen doppelt und die Summen springen.

Was ist der Unterschied zwischen Datenmodell und Datenmodellierung? Das Datenmodell ist das fertige Ergebnis, also die Tabellen und ihre Beziehungen. Datenmodellierung ist die Arbeit davor: das Aufteilen, Verbinden und Definieren. Gute Datenmodelle entstehen nur durch bewusste Datenmodellierung.

Wie oft sollte sich ein KPI Dashboard aktualisieren? Das hängt von der Entscheidung ab. Für einen Vorstandsbericht reicht oft die tägliche Aktualisierung, für den Vertrieb kann stündlich sinnvoll sein. Mit einer Pro-Lizenz sind bis zu acht geplante Aktualisierungen pro Tag möglich.

Kann ich mein bestehendes Excel-Dashboard übernehmen? Die Zahlen und die Logik ja, die flache Struktur besser nicht. Bauen Sie die Excel-Tabelle in ein Sternschema um, dann erben Sie die Rechenfehler der alten Datei nicht mit.

Wer sollte die Kennzahlen definieren? Die Fachabteilung legt fest, was eine Kennzahl bedeuten soll, und das Modell hält diese eine Definition fest. So wird aus einem Bauchgefühl eine prüfbare Zahl.
