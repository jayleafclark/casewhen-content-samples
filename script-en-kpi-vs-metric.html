A metric is anything you can count. Revenue, sessions, average handle time, rows loaded last night. All metrics. A KPI is the small set of those numbers you've tied to a goal, given a target, and agreed to act on. Every KPI is a metric. Only a few metrics earn the KPI label. The test is three questions. One, is there a target this number gets measured against. Two, does one named person own it. Three, if the number moves, does someone change what they do next week. Three yeses, you've got a KPI. Fewer than three, you've got a metric you keep for context, and it should sit in the background." PAYOFF (ON-SCREEN numbered takeaway): "Takeaway 1: run the three-question test - target, owner, decision. No target and no owner, and you're looking at a metric."
